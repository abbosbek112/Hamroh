# Focus Timer Sounds

Bu papkada Focus Timer uchun background sound fayllari saqlanadi.

## Kerakli fayllar:

1. **rain.mp3** - Yomg'ir ovozi
2. **fire.mp3** - Olov/o't ovozi  
3. **forest.mp3** - O'rmon/tabiat ovozi
4. **cafe.mp3** - Kafe/coffee shop ovozi

## Fayllarni qo'shish:

1. Yuqoridagi nomlar bilan MP3 fayllarni yuklab oling
2. Ular bilan bu papkaga qo'ying
3. Fayllar avtomatik ravishda Focus Timer'da ishlaydi

## Manbalar (bepul sound fayllar):

- **Mixkit**: https://mixkit.co/free-sound-effects/
- **Pixabay**: https://pixabay.com/music/
- **Freesound**: https://freesound.org/

## Format talablari:

- Format: MP3
- Bitrate: 128-192 kbps (yetarli)
- Duration: Loop qilinadi, qisqa fayllar ham ishlaydi
- Size: Har bir fayl 1-3 MB orasida bo'lishi tavsiya etiladi

## Eslatma:

Agar fayllar bo'lmasa, Focus Timer ishlaydi, lekin sound tanlash tugmalari ishlamaydi.
